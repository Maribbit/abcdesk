## 09 原创曲目：《雨灯与归舟》

一首以摇曳舟歌为主题的原创室内乐小品：雨灯中的应答、明亮的水光、小调夜桥、四四拍的风起，最后回到主题并安静收束。编排围绕主题变奏、功能和声与声部应答展开，同时覆盖多种 ABC 记法。

实写 **49 小节**，A 段经一、二房反复展开后共 **56 小节**；100% 速度下约 **1 分 48 秒**（不含合成器尾音）。源码按乐段交错排列四声部，每段均有中文注释。以下小节号按实写顺序、把两个结尾分别计数，便于和源码对照。

| 乐段 | 实写小节 | 调性 / 拍号 / 速度 | 编排重点 |
| --- | --- | --- | --- |
| A · 雨灯 | 1–9 | G 大调，6/8，附点四分音符 = 66 | 旋律与后半拍应答；前七小节共同反复，一、二房各一小节；分解和弦与转位低音 |
| B · 水光 | 10–17 | D 大调，6/8，附点四分音符 = 72 | 音区抬高、附点节奏、三连音与倚音；同音延音线 |
| C · 夜桥 | 18–25 | E 小调，3/4，四分音符 = 90 | 歌唱性的长线条、临时升号、属七与减七和弦、回音装饰 |
| D · 风起 | 26–33 | G 大调，4/4，四分音符 = 108 | 切分柱式和弦、和弦内多音、三连音、重音 / 断奏 / 保持音、渐强弱与延长号 |
| A' · 归舟 | 34–41 | G 大调，6/8，附点四分音符 = 66 | 动机变奏与声部应答、短倚音、十六分音符；第 39 小节五连音占三个八分音符 |
| 尾声 · 灯远 | 42–49 | G 大调，6/8，附点四分音符 = 56 | 织体减弱、低音跨小节延音，以 G6 和弦收束 |

### 声部与记谱覆盖

- **旋律**：主导主题与装饰，承载和弦符号和全曲速度变化。
- **应答**：独立旋律线与和声长音，包含普通休止和整小节休止 `Z`。
- **织体**：分解和弦、切分伴奏、柱式和弦及和弦延音线；与自动伴奏是两条不同的发声来源。
- **低音**：根音 / 五度、斜杠和弦的转位低音、跨小节持续音，使用低音谱号。
- **自动和弦伴奏**：由 `"G"`、`"D/F#"`、`"Em7"`、`"Cmaj7"`、`"F#dim7"`、`"Dsus4"` 等符号生成的第五条音轨；音量刻意较轻，可独立关闭。
- 另含谱表分组 `%%score`、声部全名 / 简称、`%%MIDI program`、行内 `K:` / `M:` / `Q:`、一二房反复、三 / 五连音、长短倚音、连奏线与延音线、力度及表情标记。曲中变速是分段阶跃，不是连续渐慢。

### 建议验证顺序

1. **整体试听**：默认全开听完整曲式；暂停并关闭「和弦伴奏」后再听，四个记谱声部仍应构成完整音乐。
2. **区分两种伴奏**：分别只保留「旋律 + 自动和弦」与「旋律 + 织体 + 低音」，确认自动和弦与显式 ABC 伴奏没有混在同一个开关里。
3. **多声部调整**：播放时展开菜单，先暂停，再连续静音应答、织体或低音；无文件更新时位置保持，手动恢复后才发声。观察菜单摘要与静音声部的谱面 / 键盘提示。
4. **反复定位与变速**：A 段第一次走一房、第二次走二房；在第二次共同段拖动定位、调至 75% / 150%，确认仍位于第二次演奏，而非跳回第一次。
5. **跨段联动**：在 C、D、A' 段观察调号、拍号、速度与多谱表对齐；定位三连音、五连音、和弦或延音处，检查高亮和「从此处播放」。
6. **长谱布局**：滚动或调整面板宽度，检查四谱表、和弦符号、装饰与渐强弱线，确认顶部控制区及底部键盘仍可用。

ABC Desk 当前统一使用钢琴音色，文件中的长笛 / 弦乐 MIDI 指令用于兼容验证，不代表此版本会输出这些乐器。此曲包含复合拍与多次变速，不应把一个无拍单位 BPM 当作整曲速度。表情、装饰和延长号是否实际影响音频，以播放器支持为准；此材料不预设所有记谱符号都已具备完整演奏语义。

自动回归见 `test/playback.test.ts`：校验 abcjs 无解析告警、四声部逐小节时值、反复与分段速度的展开时长、自动和弦独立成轨及声部静音。实际音色平衡、悦耳程度和 F5 布局仍需人工试听 / 查看。
