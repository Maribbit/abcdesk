# 个人档案

> 给 agent 的约束清单；所有新材料必须满足这里的限制。按阶段推进时更新"当前阶段"一节，不在这里写每次练习的流水账（那在各课的 `session.md`）。

## 乐器与条件

- 乐器：88 键钢琴（A0–C8）。
- 双手一起练；左手型刻意简单，右手负责乐句。
- 踏板：有延音踏板；踏板只写在文字说明里，不依赖播放器表现。
- 每次练习 15 分钟左右，宁可短而专注，不追求一次练很久。

## 方向与声音偏好

- 曲风：**氛围钢琴**（安静、慢、少音符、长延音、留白多）。
- 目标：**自己能即兴弹出一段**，而不是背完整曲。乐句短、可重复，不追求炫技。
- 接受轻微"糊"的和声色彩（后期的 add9 / sus2 / maj7），不要跳跃的节奏。
- 速度 60–85 BPM；练习时可以用播放器再降速。

## 自述的基础（2026-11-02）

- 没有系统学过钢琴或乐理；能找到白键的位置，知道中央 C。
- 对拍子不太有把握，节奏一复杂就跟不上。
- 其他困难待练习中自述补充。

## 当前阶段：0–1（安静地开始 → 一个和弦的空间）

| 维度 | 当前允许 | 暂不允许 |
| --- | --- | --- |
| 调性 | C 大调白键 | 任何黑键 |
| 右手音高 | 阶段 0：任意白键；阶段 1：E G A → C D E G A（五声） | F、B（容易撞低音） |
| 右手音区 | C4–C6 | 更高或更低 |
| 左手 | 单一低音：C2+C3 八度长音 → C–G 五度 → 慢速 1–5–8 分解 | 换和弦、跨小节节奏型 |
| 节奏 | 全音符、二分音符、四分音符；大量休止 | 八分音符、附点、三连音、切分 |
| 速度 | Q: 1/4=60 | 更快 |
| 结构 | 示范 ≤ 4 小节 + 等长空白；全曲 ≤ 16 小节 | 更长 |
| 和声 | 单一和弦（C） | 两个及以上和弦 |

## 阶段推进的总路线

0 安静地开始 → 1 一个和弦的空间 → 2 两个和弦（Am ↔ F）→ 3 四和弦循环（Am–F–C–G）→ 4 色彩与空间（开放排列、高音区、add9 / sus2）→ 5 调式与转换 → 6 自己的片段。
