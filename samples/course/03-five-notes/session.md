# 03 · 五个音

## 当前进展 / 下次继续

尚未开始。等 02 的出口达成后再开。

## 本课目标

- 左手改为慢速 1–5–8 分解：C2、G2 各两拍，再 C3 一整小节；两小节一循环。
- 右手扩到 **C、D、E、G、A** 五个音（C4 五指位置，正好 1–5 指）。
- 新规则：**每句结尾落在 C 或 E**；中间随意。

## 练法

1. 听：全开播放两遍，分辨两句示范分别落在 C 和 E 上。
2. 左手先单独跟两轮 1–5–8，确认不乱。
3. 跟：静音"右手示范"，开循环，加右手接句。
4. 撤提示：隐藏键盘提示再接两轮。
5. 记：下面写两三行。

左手一动右手就乱：先回到 02 的五度长音练右手规则，不要两头一起加难度（可请 agent 把 `left` 声部临时改回长音，并在历史里记一笔）。

## 出口（达成就进入阶段 2）

- 左手 1–5–8 能稳定循环，右手同时接句不中断。
- 不看提示也能让句子落在 C 或 E 上。
- 觉得五个音"够用了"，想换和弦。
