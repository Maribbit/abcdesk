# 学习指南（给外部 agent 与我自己）

这是一套面向**氛围钢琴即兴**的自学课程，使用 ABC Desk 作为示范、伴奏与循环练习的工具。本文件说明 agent 的阅读顺序、调整同一练习的规则、反馈记录方式，以及没有演奏输入时的能力边界。目录与文件名只是本课程的约定，不是 ABC Desk 的硬性要求。

## 阅读顺序

1. `profile.md`：我的条件、偏好与约束——所有新材料都必须满足这里的限制。
2. 当前练习目录下的 `session.md`：顶部"当前进展 / 下次继续"是本次会话的起点；下方历史按次追加。
3. 当前练习目录下的 `exercise.abc`：音乐材料本身，修改时**保持路径不变**，已打开的预览会自动更新。
4. 本文件其余部分：调整规则与记录格式。

## 每课的结构：呼叫—应答

每个 `exercise.abc` 都是一个可整段循环的短片段，由两个记谱声部组成：

| 声部 | 含义 | 练习时怎么用 |
| --- | --- | --- |
| `demo`（右手示范） | 一句或两句短乐句，后面接等长的空白小节 | 先听；熟悉后在预览的声部菜单里**静音**，空白处由我接句 |
| `left`（左手） | 本课要一起弹的左手型，全程不停 | 一直保留；它既是我的左手任务，也是接句时的伴奏 |

空白小节在谱面上标有"你来接"。循环播放时，示范和空白交替出现，相当于一条无限长的伴奏带。

一次练习约 15 分钟：

1. **听**（3 分钟）：全开播放，看谱面与键盘高亮，不弹。
2. **跟**（5 分钟）：静音 `demo`，开启循环，左手跟 `left`，右手在空白处按本课规则接句。嫌快就降速。
3. **撤提示**（5 分钟）：隐藏键盘提示（可再隐藏谱面），只听伴奏接句。
4. **记**（2 分钟）：在 `session.md` 写两三行自述。

## 调整同一练习的规则

- **针对自述的困难改，不换新练习。** 例如"音找得到，一换节奏就跟不上"→ 保留音高材料，只简化节奏；"左手一动右手就停"→ 左手改回长音，右手材料不变。
- **一次只改一个维度**：音高集合、节奏、速度、左手型、音区，五选一。
- **不突破 `profile.md` 的当前阶段限制**；要进入下一阶段，先在 `session.md` 记录"本课出口达成"，再新建下一课目录。
- 示范乐句 ≤ 4 小节，空白与示范等长；全曲 ≤ 16 小节。
- 速度写在 `Q:` 里，默认 60；练习中的临时降速用播放器，不改文件。
- 只用 ABC Desk 能发声的手段：钢琴音色、声部静音、整段循环、变速。不依赖鼓、合成器或踏板记号的播放效果（踏板只写在文字说明里）。
- 修改 `exercise.abc` 后，在 `session.md` 历史里写一行"改了什么、为什么"。

## 反馈记录格式（`session.md`）

```text
# 课名

## 当前进展 / 下次继续
（一两句：练到哪、下次从哪开始、当前最大的困难）

## 本课目标
## 练法
## 出口（达成就进入下一课）

## 历史（按次追加，最新在下）
### 2026-11-05
- 自述：……（我的原话，不改写）
- agent 建议：……（标明是建议）
- 调整：……（改了文件的哪一处，为什么；没改就写"无"）
- 下一步：……
```

## 诚实性边界

- ABC Desk 和 agent **听不到我弹**。所有关于"弹得怎样"的判断只来自我的自述；agent 不得写"已听到""已确认能弹"之类的话。
- 记录区分**我的自述**与 **agent 建议**；建议不等于已验证的能力。
- 没有把握的乐理结论要说"可能"，不要替我下结论。
- 不自动生成下一课：是否前进由我在 `session.md` 里写"出口达成"决定。

## 阶段路线（概览）

| 阶段 | 课 | 要解决的事 |
| --- | --- | --- |
| 0 · 安静地开始 | 01 | 坐下、踏板、听延音、敢于留白 |
| 1 · 一个和弦的空间 | 02、03 | 在固定低音上用 3 个音、再用 5 个音接句 |
| 2 · 两个和弦 | 待写 | 听到和弦变化，换和弦时落在和弦音上 |
| 3 · 四和弦循环 | 待写 | 乐句的起落与呼吸 |
| 4 · 色彩与空间 | 待写 | 开放排列、高音区点缀、add9 / sus2 |
| 5 · 调式与转换 | 待写 | 同一组白键，不同的重心 |
| 6 · 自己的片段 | 待写 | 撤除全部提示即兴 1 分钟 |

后续阶段只在前一阶段"出口达成"后再写，材料按当时的自述调整。
