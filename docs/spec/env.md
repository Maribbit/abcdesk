# ENV：运行环境与安全

> 依据：D0 设计 §7；计划 §5 第 15、16 条；§7 清单第 15、16 项。
> 受 E03（最低 VS Code 版本与兼容性）及实测阈值影响的部分仅登记于 `docs/plan.md`，不写成条目。

### SPEC-ENV-01 受限模式声明
- 规范：`package.json` 的 `capabilities` 声明：`untrustedWorkspaces` 完整支持（supported）；不将 `virtualWorkspaces` 标记为不支持，即不主动禁用虚拟工作区。
- 验证：auto
- 里程碑：M0
- 依据：D0 设计 §7；计划 §7 清单第 15 项

### SPEC-ENV-02 受限模式行为一致、不降级
- 规范：受限模式与信任模式下预览、播放、联动、导出与练习设置记忆行为一致、不降级、不弹信任请求；ABC 仅作记谱数据解析，不执行工作区代码，不读取工作区提供的路径、外部程序、URL 或脚本类设置；受限模式下写入只经用户确认的原生保存对话框，不自动创建或修改工作区文件；工作区状态记录仅含文件 / 曲目 / 声部标识与轻量设置。
- 验证：manual
- 里程碑：M0
- 依据：D0 设计 §7；计划 §7 清单第 15 项

### SPEC-ENV-03 不受信任内容与 CSP
- 规范：webview 中来自文件的标题、声部名、告警文案与路径一律按文本渲染，不拼接为 HTML；CSP 只允许带 nonce 的自有脚本与扩展自有资源，不放行远程脚本或远程资源；ABC 排版与 MIDI 指令不得触发资源加载或脚本执行。
- 验证：manual
- 里程碑：M0
- 依据：D0 设计 §7；计划 §7 清单第 15 项

### SPEC-ENV-04 消息桥输入校验
- 规范：扩展侧不信任 webview 消息：按消息类型、数值范围与当前文档版本校验；拒绝缺类型、越界范围、版本不符或含任意路径的消息，不据此执行文件操作。
- 验证：auto
- 里程碑：M0
- 依据：D0 设计 §7；计划 §7 清单第 15 项

### SPEC-ENV-05 扩展侧不用 Node fs 与本机路径
- 规范：扩展侧读取文件仅用 VS Code 文档与 `workspace.fs` API，不依赖本机路径与 Node `fs`；音色与 webview 资源仅经 `asWebviewUri` 加载；音频与键盘可视化只在本机 webview 完成；核心代码避免 Node 专用依赖（vscode.dev 不承诺，但不主动堵死）。
- 验证：auto
- 里程碑：M0
- 依据：D0 设计 §7；计划 §5 第 15 条

### SPEC-ENV-06 Remote 兼容冒烟
- 规范：至少在 WSL 或 SSH 之一完成冒烟：打开、预览、播放、外部写入后更新、导出保存到远端工作区；记录首次音色加载时长与失败表现；虚拟工作区无法读取或保存时按来源不可用与导出失败规则提示并记录实际行为。
- 验证：manual
- 里程碑：M0
- 依据：D0 设计 §7；计划 §7 清单第 15 项

### SPEC-ENV-07 零网络与零遥测
- 规范：预览、播放、导出全程不发起任何网络请求、不收集遥测、不上传 ABC / 学习记录 / 播放器状态；仅内置钢琴音色；`%%MIDI program` 等乐器指令播放时统一使用钢琴音色并标明"首版仅钢琴音色"；MIDI 导出保留 ABC 材料中的乐器指令；abcjs 默认远程音色地址不得被触发。
- 验证：manual
- 里程碑：M0
- 依据：D0 设计 §7；计划 §7 清单第 15 项

### SPEC-ENV-08 激活事件清单
- 规范：`activationEvents` 恰为 `onLanguage:abc`；不使用 `workspaceContains`、`onStartupFinished` 或 `*`；命令依赖 `contributes.commands` 自动激活（VS Code 1.74+），不手写 `onCommand` 激活事件。
- 验证：auto
- 里程碑：M0
- 依据：D0 设计 §2、§7；计划 §5 第 16 条

### SPEC-ENV-09 激活零开销
- 规范：未打开 ABC 的工作区启动后扩展不激活（Running Extensions 核对）；激活本身不创建预览、不加载音色、不弹通知；记录激活耗时与打包体积，确认音色不在激活时读入。
- 验证：manual
- 里程碑：M0
- 依据：D0 设计 §2；计划 §7 清单第 16 项
