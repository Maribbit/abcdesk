# EXP：导出

> 依据：D0 设计 §3（MIDI / SVG 导出）、§2；计划 §7 清单第 13、14 项与"M1 导出验收补充"。
> 无预览独立路径、快照隔离与曲目确认属 M0 spike 验证；格式完整性、保存流程与失败报告在 M1 完整验收。
> 全部条目采用 manual 验证（登记见 `docs/manual-checks.md`）。

### SPEC-EXP-01 导出版本与来源快照
- 规范：使用执行命令时目标文档的当前内容快照，包括未保存修改；有可用编辑器文档时以该文档为准，否则读取对应文件，不用磁盘旧版覆盖缓冲区、不把预览缓存当来源；来源按命令目标规则锁定，从预览发起时使用其绑定文档，不跟随另存为后变为活动状态的其他文件；预览 / 播放版本落后时明确提示"导出当前文档，非正在播放 / 显示的版本"，未保存内容标明"包含未保存修改"；首版不提供导出旧快照的选项；无有效输出时说明原因，不回退旧数据。
- 验证：manual
- 里程碑：M0
- 依据：设计 §3（MIDI / SVG 导出）、§2；计划 §7 清单第 13 项

### SPEC-EXP-02 多曲目每次确认一首
- 规范：单曲文件直接准备，不显示选择列表；多曲目每次先从当前文档快照的列表确认一首，显示序号、`X:` 和标题；可预选可靠对应的预览当前曲目或调用时源码光标所属曲目，仍须确认，无可靠预选时不代替用户选择；取消无副作用；选择只用于本次导出，不改变预览选曲或播放；不提供整集拼接 / 批量导出。
- 验证：manual
- 里程碑：M0
- 依据：设计 §3；计划 §7 清单第 14 项

### SPEC-EXP-03 导出任务绑定与写入前校验
- 规范：导出任务绑定文档身份、内容版本、已确认曲目范围和格式；曲目选择期间、准备期间及保存对话框返回后、开始写入前再次校验；已发现内容变化、身份迁移或来源不可用时取消本次写入、提示重新导出，不自动改用新版、不无限重试；从预览发起的任务在该面板关闭后也取消；仅切换焦点不改变导出目标。
- 验证：manual
- 里程碑：M0
- 依据：设计 §3；计划 §7 清单第 14 项

### SPEC-EXP-04 独立准备与播放隔离
- 规范：没有预览也可导出，不要求创建 / 显示音乐预览、加载音色或先播放；已有有效同版本数据可在不污染播放器状态的前提下复用；导出不主动暂停、定位、换版、展开提示或接替其他预览的音乐，不解除旧谱与新源码的联动禁用（原生界面操作导致面板隐藏仍按暂停规则）；取消 / 完成导出均不自动续播；只生成该格式必要的数据，不把 MIDI 生成等同于音频采样合成；导出任务不写回播放器的速度、声部设置、待更新状态或持久记录；渲染 / 音频 / 导出能力分别判断，音频准备失败或超限不直接禁止按格式独立导出。
- 验证：manual
- 里程碑：M0
- 依据：设计 §3；计划 §7 清单第 13 项

### SPEC-EXP-05 MIDI 仅按 ABC 材料
- 规范：MIDI 仅按 ABC 材料，不应用播放器速度百分比、声部静音覆盖、自动和弦伴奏开关、临时节拍器、当前位置或整段循环，不提供"按当前练习设置"模式；界面说明"按 ABC 原速度与声部导出，不含播放器练习设置"；保留 ABC 本身受支持的速度（含曲中变速）、反复、记谱声部及伴奏 / MIDI 指令；自动伴奏采用由材料与明确的导出默认配置确定的行为，不借用历史播放器开关；导出所确认曲目的完整有限演奏序列，不包含其他曲目、不从当前播放位置截取、不展开播放器无限循环；MIDI 是音乐事件数据，不含本地钢琴音色录音、不承诺在其他播放器中听到完全相同的音色；支持范围与缺省行为需验证，不承诺 abcjs 未支持的指令。
- 验证：manual
- 里程碑：M1
- 依据：设计 §3；计划 §7（M1 导出验收补充）

### SPEC-EXP-06 SVG 外观与安全
- 规范：SVG 为白色背景、黑色谱面，包含乐谱标题与记谱内容，不含工具栏、键盘、播放光标、查阅选择或源码联动高亮；隐藏提示不影响完整谱面的导出、也不改变界面的提示显隐；使用独立且稳定的导出排版基准，不受预览主题、窗口宽度、滚动或缩放状态影响；长谱完整输出，不只导出可视部分或第一个 SVG 片段；输出可脱离 VS Code 正常显示，不依赖 `--vscode-*`、webview 样式或临时资源地址，不携带脚本、事件处理器和不必要的本地路径信息；多片段合并与外部资源 / 字体策略需实现中校验。
- 验证：manual
- 里程碑：M1
- 依据：设计 §3；计划 §7（M1 导出验收补充）

### SPEC-EXP-07 保存流程与命名建议
- 规范：沿用两个导出命令与预览"更多"入口，不新增公开命令；准备有效数据后使用 VS Code 原生保存对话框；已保存文档默认使用源文件基本名加 `.mid` / `.svg`，未保存文档参考有效曲名、无曲名用 `Untitled`；多曲目在建议基本名后附加本次所选曲目的序号与可用曲名，避免不同曲目默认重名，名称清理后仅作可修改建议、序号不作为设置身份；用户确认目标路径与覆盖，取消不写文件、不保存 ABC、不改变预览绑定或练习设置；不得以导出覆盖来源 ABC；仅在写入成功后报告成功，不自动打开导出文件或启动外部播放器；用户明确保存的导出文件可产生 git 改动，与练习设置不写项目文件的规则区分。
- 验证：manual
- 里程碑：M1
- 依据：设计 §3；计划 §7（M1 导出验收补充）

### SPEC-EXP-08 失败报告与格式能力判断
- 规范：内容不能生成目标格式时说明原因，不导出旧参考谱；空白内容不生成空壳文件，合法全休止符不视为空白，普通告警不一律阻止导出；写入权限 / 路径错误不标成 ABC 行错误；无预览时也提供可见的进度、取消与失败反馈，不因此打开音乐预览；导出准备取消 / 超时后不得开始写入、保存对话框返回后重新核验任务有效性（取消与写入边界细节见 PERF-09）。
- 验证：manual
- 里程碑：M1
- 依据：设计 §3；计划 §7（M1 导出验收补充）
