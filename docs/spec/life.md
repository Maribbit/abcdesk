# LIFE：文件生命周期

> 依据：D0 设计 §5、§6；计划 §5 第 10、11、20 条；§7 清单第 10 项。
> 本域行为依赖真实文件事件与编辑器运行时，全部条目采用 manual 验证（登记见 `docs/manual-checks.md`）。

### SPEC-LIFE-01 每文档绑定预览
- 规范：每文档绑定预览：同一文档在同一 VS Code 窗口内复用同一预览；多个文档（含多个未保存 ABC 文档）分别绑定，不按标签名或相同内容合并；切换活动编辑器不改变绑定；主动预览其他文件时打开其独立预览，不替换当前练习；第一版不提供跟随 / 固定开关；恢复先前已打开的预览不视为自动新建。
- 验证：manual
- 里程碑：M0
- 依据：计划 §5 第 10 条；设计 §5、§6

### SPEC-LIFE-02 未保存新文档与保存操作边界
- 规范：语言模式为 ABC 的未保存文档即可主动预览、播放与联动，不强制先保存；明确显示"尚未保存；与外部 agent 协作前请先保存"，不反复弹通知；练习设置仅保留在当前会话，不将临时文档标识写入持久记录；保存、另存为、放弃未保存内容使用 VS Code 原生操作与确认，插件不代为保存、不缓存全文、不静默覆盖；取消保存或取消关闭不破坏原预览；真正放弃且来源文档不可用时进入来源不可用状态。
- 验证：manual
- 里程碑：M0
- 依据：计划 §5 第 10 条；设计 §6

### SPEC-LIFE-03 首次保存与重命名接续
- 规范：能可靠确认原文档与目标对应关系时，首次保存、重命名 / 移动视为同一练习：目标无冲突时接续原预览并更新来源标识与显示路径，当前设置随之接续，持久记录迁移受记忆开关约束；身份切换先暂停并取消待起播、旧异步任务与未提交定位，再重新核验目标内容与映射；同一面板且内容未变时保留暂停位置，内容变化则应用新版本并归零；声部静音仍需结构校验；不自动续播、不抢焦点、不新建已关闭预览；不能只凭先关闭后打开、同名、相同正文或相邻文件事件推断；无法确认时不自动改绑或迁移，原来源不可用则显示状态。
- 验证：manual
- 里程碑：M0
- 依据：计划 §5 第 10 条；设计 §5、§6

### SPEC-LIFE-04 可靠迁移的目标冲突
- 规范：目标已有预览或设置记录时目标已有状态优先；暂停受迁移影响的预览并取消旧请求，不自动续播或抢焦点；目标已有面板继续作为唯一可播放预览，重新核验实际文档与曲目；目标设置按记忆开关、曲目与声部规则校验，无效记录回退默认值，不用来源记录填补或混合；来源面板若存在保留为"文件已迁移"只读状态页：旧谱仅明确标为参考，不再执行旧绑定的播放、定位、设置修改或导出，仅提供明确的目标预览入口；只有目标设置而没有目标面板时不自动创建面板；不自动关闭来源页、打开目标页或恢复任何旧请求；无可靠迁移关系时不套用目标优先规则。
- 验证：manual
- 里程碑：M0
- 依据：计划 §5 第 20 条；设计 §6

### SPEC-LIFE-05 已有文件另存为
- 规范：已有文件另存为视作另一份练习：原预览继续绑定原文件，不追随另存为后自动变为活动状态的新源码；新文件须主动打开 / 播放才创建或复用自己的预览；原设置不复制到新路径，新目标已有记录时遵循自己的设置与声部校验，无记录时用默认值；原文件内容仍以当前有效文档 / 磁盘为准，若因此变化沿用待更新规则；仅关闭源码标签不关闭预览。
- 验证：manual
- 里程碑：M0
- 依据：计划 §5 第 10 条；设计 §6

### SPEC-LIFE-06 来源确认不可用
- 规范：原文件被删除 / 无法读取且没有可用编辑器缓冲区时：保留已有预览页，显示来源状态与原路径；立即停音、取消起播和过期任务，清除播放标记与旧源码联动；最后成功谱面仅供参考，不允许播放或将其作为最新版本导出；不自动关闭、重建原文件、搜索替代文件或改绑新路径；状态不随"隐藏提示"消失，也不强行显示已隐藏谱面；VS Code 仍保留可用编辑器缓冲区时继续按该文档预览并提示磁盘状态，保留未保存修改，冲突沿用原生处理；插件缓存的旧正文不算可用缓冲区；不能因一次删除事件就丢弃用户编辑。
- 验证：manual
- 里程碑：M0
- 依据：设计 §5、§6；计划 §7 清单第 10 项

### SPEC-LIFE-07 来源恢复可用
- 规范：原路径重新可读时，已有预览重新获取并校验当前内容，应用后默认位置归零，不恢复旧起播或旧映射；有效声部仍按 §5 规则校验；重新可读本身不播放、不抢焦点，也不复活用户已关闭的预览。
- 验证：manual
- 里程碑：M0
- 依据：设计 §5、§6；计划 §7 清单第 10 项

### SPEC-LIFE-08 文件事件鲁棒性
- 规范：短暂删除再创建须合并核验，不能仅凭单次通知认定永久丢失；外部原子替换、读取失败与恢复、目标冲突及异步事件乱序不得造成误判；无法可靠确认时不自动改绑或迁移；确认来源不可用后及时停音；防抖与判定策略由 M0 实测记录。
- 验证：manual
- 里程碑：M0
- 依据：设计 §6；计划 §7 清单第 10 项

### SPEC-LIFE-09 外部协作边界与学习资产
- 规范：插件不集成 AI 对话、不提供命令唤起特定 chat 的集成；文件是基础协作接口，普通文件系统 agent 不能假设读到未保存的编辑器内容，交给 agent 修改前先保存，冲突沿用 VS Code 原生处理；学习资产（`learning-guide.md`、`profile.md`、`session.md`）为可选轻量模板，由用户与外部 agent 维护，目录与文件名不是插件硬编码要求，插件不解析或自动写回学习档案，独立 ABC 不依赖这些文件；状态保存不写 ABC、学习档案或额外项目配置文件，播放器操作不产生项目 git 改动。
- 验证：manual
- 里程碑：M0
- 依据：计划 §5 第 11 条；设计 §6
