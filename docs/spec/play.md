# PLAY：播放与练习控制

> 依据：D0 设计 §3（核心交互、窄窗口与低高度适配）；计划 §5 第 12、13、18 条；§7 清单第 5、8、11、18 项。
> 本域行为依赖真实音频、渲染与交互运行时，全部条目采用 manual 验证（登记见 `docs/manual-checks.md`）。
> 阻断：P01（非循环自然结束后的位置与再次播放）、P02（反复音符默认起播落点）、P03（节拍参照入口与语义）、P06（速度输入与进度键盘细节）——未确认前不补造默认值、不实现对应行为，见 `docs/plan.md` 阻断表。

### SPEC-PLAY-01 起播准备与取消
- 规范：先渲染乐谱，首次明确播放才准备音频；仅查看谱面不主动预备，已准备资源可复用；点击播放显示"正在准备音频…"（只显示真实阶段、不伪造百分比），成功后执行这次仍有效的请求、无需再点一次；准备期间再次普通播放 / 暂停（按钮、命令、预览局部空格）取消起播并保留最后已提交位置、不提交仍在准备的定位目标，"停止"取消并归零；准备按钮显示"取消起播"并同步可访问名称，不明文禁用；播放中的内部缓冲保留暂停语义，暂停取消续播；隐藏、关闭、请求被接替、目标版本失效或准备超时后，旧任务完成不得发声；新预览起播前先暂停旧预览，同一窗口内只允许一个预览发声；有待更新文档时按 STATE-07 暂停换版规则优先；旧取消回调不得清掉之后的新显式请求。
- 验证：manual
- 里程碑：M0
- 依据：设计 §3；计划 §5 第 13、20 条

### SPEC-PLAY-02 播放暂停与位置语义
- 规范：普通播放 / 暂停控制当前播放位置，不因查阅选中另一音符而跳转；普通暂停且无内容变化时保留位置；失焦继续播放，面板隐藏则暂停、恢复后不自动播放；仅隐藏谱面 / 键盘提示不暂停；手动切曲与关闭重开归零（见 DOC / SET 域）；播放中的变速与定位内部重建可短暂缓冲后继续当前快照，不视为用户暂停、不触发文件换版；期间出现暂停、停止、隐藏、关闭或播放接替时必须取消续播。
- 验证：manual
- 里程碑：M0
- 依据：设计 §3；计划 §5 第 12、13 条

### SPEC-PLAY-03 停止与循环
- 规范：停止立即停音并回到开头；循环默认关闭，开关本身不启动播放、不修改 ABC；循环回到开头不触发换版；有待更新内容时停止仍按 STATE-07 应用最新版本；非循环自然结束不连播其他曲目，其后的位置与再次播放行为待 P01 确认，不补造默认。
- 验证：manual
- 里程碑：M0
- 依据：设计 §3；计划 §5 第 13 条

### SPEC-PLAY-04 速度控制
- 规范：百分比为主控，默认 100%、范围 25%～200%；支持输入与"恢复原速"（100%），只调整试听、不修改 ABC 速度标记；可可靠换算时辅助显示带拍单位（如"速度 75%，四分音符 = 90"），无法可靠换算时不显示猜测值，曲中变速按所在位置解释、不用无拍单位 BPM 冒充整曲速度；输入完成并提交后应用、不随每个字符反复重建音频；播放中变速保持乐曲中的位置（含反复中的演奏位置）而非原来的秒数，允许短暂缓冲后继续；暂停时变速不发声。（输入提交、失焦与非法值细节待 P06。）
- 验证：manual
- 里程碑：M0
- 依据：设计 §3；计划 §7 清单第 11 项

### SPEC-PLAY-05 进度定位
- 规范：进度条按含反复的实际演奏顺序展开，可定位第二次反复，与源码查阅位置分开；拖动预览、松手提交，播放中拖动时原音乐继续、只预览目标时间，松手后执行一次定位并继续；暂停中拖动只改变下次起点、不发声；点击进度条直接定位，保持播放 / 暂停状态；取消拖动不提交位置；停止、隐藏、播放接替或自然结束等事件不得被后到的拖动提交覆盖、不得因此重新起播；拖动目标所属版本失效时取消该定位，不套用到新版本。（进度键盘步长与提交时机待 P06。）
- 验证：manual
- 里程碑：M0
- 依据：设计 §3；计划 §7 清单第 11 项

### SPEC-PLAY-06 声部控制与静音调整
- 规范：声部使用折叠菜单提供各声部发声开关，菜单关闭时仍显示静音摘要（如"已静音 1 个声部"）；展示 ABC 实际声部，不强制第一声部为示范；自动生成的和弦伴奏轨有独立控制，不与显式 ABC 伴奏声部混为一谈；第一版先暂停再调整——播放中菜单可查看、开关需暂停后才能修改，菜单提供"暂停以调整声部"入口，自动和弦伴奏开关遵循同一规则；无文件更新时暂停与连续调整多个声部保留乐曲位置，调整后由用户手动播放、不自动续播；有待更新文件时暂停先应用最新版本并重置到开头，随后调整新版本的声部；从光标起播时多声部按所选时刻及现有静音设置播放，不自动独奏；静音覆盖的保存与恢复校验见 SET 域。
- 验证：manual
- 里程碑：M0
- 依据：设计 §3；计划 §5 第 13 条

### SPEC-PLAY-07 隐藏提示
- 规范："隐藏提示 / 显示提示"按钮一次隐藏谱面与键盘的可视内容，保留控制区、进度与状态信息；不改变声部静音状态、不暂停音乐、不暂停演奏时间跟随；恢复时还原之前的显示状态，例如原先收起的键盘仍保持收起；隐藏时显示"提示已隐藏"与"显示提示"入口；只作用于预览，不隐藏原生源码；已隐藏的提示不因光标移动、播放事件、错误或恢复重新显示。
- 验证：manual
- 里程碑：M0
- 依据：设计 §3；计划 §5 第 13 条

### SPEC-PLAY-08 键盘可视化初始与音域
- 规范：没有该文件的有效保存设置时键盘默认展开，有记录时按 SET 域恢复；默认采用当前曲目整首记谱材料的音域、不合并文件内其他曲目，至少保留两个八度的参照空间；可切换完整 88 键（A0～C8），标记各 C 的八度、中央 C 标为 C4；音域按当前显示的文档版本计算，同版本内不随音符或声部静音变化而伸缩，播放中收到新版本不提前重排旧谱对应的键盘；窄窗口保持可辨认键宽、放不下时允许手动横向滚动，不强行压缩 88 键、不自动收起；播放不驱动键盘自动横移，可视窗口外有提示音时显示方向提示、不把手动浏览拉回播放位置；超出 A0～C8 的音符明确提示、不折返到其他八度；低高度时保持展开偏好并随内容纵向滚动；手动收起后不因播放、声部切换或面板恢复而展开。
- 验证：manual
- 里程碑：M0
- 依据：设计 §3

### SPEC-PLAY-09 键盘提示语义与琴键操作
- 规范：键盘提示跟随记谱材料的演奏时间、包含静音声部，并标明"乐谱提示，含静音声部"；静音不撤掉对应键盘提示或谱面音符，谱面时间跟随继续；亮键不表示用户真实按键、演奏正确或该音必然正在发声（首版没有演奏输入检测）；显式写入 ABC 的伴奏声部属于记谱材料、可显示提示，自动生成的和弦伴奏不默认混入记谱提示；琴键仅作可视提示，不提供点击试听，不改变播放位置或谱面选择，不呈现可演奏按钮的暗示。
- 验证：manual
- 里程碑：M0
- 依据：设计 §3；计划 §7 清单第 8 项

### SPEC-PLAY-10 伴奏路线与听验收范围
- 规范：伴奏优先使用 abcjs 内置能力（和弦符号轨），不自建伴奏引擎；兜底路线为显式写出 ABC 第二声部伴奏，M0 听验两条路线、至少一条可用即通过；自动和弦伴奏不默认纳入记谱提示与键盘；伴奏风格 / 织体、`voicesOff` 与节拍器的实际行为需 M0 听验，不能仅凭 abcjs 参数反推产品行为（节拍参照的入口与默认值待 P03）。
- 验证：manual
- 里程碑：M0
- 依据：计划 §5 第 6 条；§7 清单第 8 项

### SPEC-PLAY-11 谱面查阅联动与标记
- 规范：点击谱面音符选中音符并定位对应源码，焦点留在预览、不改变播放位置、不额外发声；停止 / 暂停时移动源码光标，属于当前曲目时突出对应谱面元素、必要时滚动使其可见，光标属于其他曲目时不自动切曲、不套用当前曲目的映射、可提示目标曲目，播放位置不变、不自动起播；播放中移动光标只更新查阅标记、不改变音乐、不抢占播放跟随的滚动；播放过程更新谱面、键盘与源码的播放高亮，不移动编辑光标、不自动滚动源码、不因播放打开已关闭的源码页；查阅标记与播放高亮可区分、不只靠颜色区别；谱面播放位置超出可视区域时自动滚动，用户手动滚动后暂停跟随并提供显式"恢复跟随"；文件变化不自动起播。
- 验证：manual
- 里程碑：M0
- 依据：设计 §3；计划 §5 第 12 条；§7 清单第 5 项

### SPEC-PLAY-12 从此处播放与起播定位
- 规范：显式"从此处播放"（从光标 / 所选音符播放）按可靠映射定位起播，无有效定位时禁用并说明原因，无有效映射时提示、不悄悄从头播放；多声部按所选时刻及现有静音设置播放，不自动独奏；普通光标移动不触发播放；从源码执行时保留源码焦点、按需创建 / 显示预览，仍遵循准备与取消规则。（反复音符的默认起播落点待 P02，不把"第一次出现"推荐当成默认规则。）
- 验证：manual
- 里程碑：M0
- 依据：设计 §3；计划 §5 第 12 条

### SPEC-PLAY-13 控件布局与尺寸适配
- 规范：常用播放操作（播放 / 暂停、停止、循环、速度、进度）与查阅 / 练习操作（从此处播放、声部、隐藏提示）位于 webview 控制区，低频导出收入"更多"；窄宽时按稳定分组自然换行（"播放 / 暂停、停止、隐藏提示""循环、速度、声部""从此处播放、更多"），不把循环、速度、声部或隐藏提示收入二级菜单、不隐藏播放 / 暂停、停止与关键状态；多曲目选择器独立成行、单曲不显示；进度独占一行；低高度时内容整体纵向滚动、至少保留播放 / 暂停与停止及关键状态摘要，不自动收起键盘、不切换隐藏提示或音域模式、不写入新偏好，滚出视口不等于面板隐藏、不触发暂停；非播放期间按最新宽度防抖重排谱面，播放期间保持排版、必要时谱面局部横滚；暂停后应用最新宽度，纯尺寸变化保留选曲、设置与演奏位置，不重新准备音频、不自动起播；布局切换不提交速度输入、曲目选择或进度拖动、不抢源码焦点；重排结果核验文档、曲目与最新布局请求，不补交旧坐标、不在关闭后恢复界面；独立 SVG 导出布局不受预览尺寸影响。
- 验证：manual
- 里程碑：M0
- 依据：设计 §3（窄窗口与低高度适配）；计划 §5 第 18 条

### SPEC-PLAY-14 首次交互前的音频恢复
- 规范：浏览器平台要求用户与预览发生真实交互后才能恢复音频设备；预览从未收到用户操作时，起播的准备在音频缓冲就绪后等待交互：状态区提示"点击预览开始播放"，不静默停留、不发声、不计为失败；用户在预览内的首次交互若不是取消 / 停止语义（点击谱面、空白等），自动继续这次仍有效的起播请求、不要求重新点击播放；首次交互若为取消 / 停止语义（点击"取消起播"、按空格、点击"停止"），按其规则执行、不自动起播；等待交互不适用准备超时：不因用户未点击而报超时或判失败、提示保持等待；用户交互后恢复系统准备的超时保护，交互后的准备长时间无结果才按超时规则处理；此后同一预览内后续播放请求不再等待交互，直接准备并起播。
- 验证：manual
- 里程碑：M0
- 依据：M0 播放主干实测（命令起播在未交互预览中等待平台音频恢复）；Chromium autoplay policy 与 abcjs prime 行为；计划 §7 清单第 5、8 项
