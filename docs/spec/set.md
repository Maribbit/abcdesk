# SET：设置与恢复

> 依据：D0 设计 §5（练习设置与临时状态）；计划 §10（设置与恢复已确认）、§7 清单第 12 项。
> 除 SET-01（当前即可静态验证）外，其余条目采用 manual 验证（登记见 `docs/manual-checks.md`）。
> 阻断：P04（无工作区记忆范围、跨工作区迁移）、P05（记录清理、多窗口写冲突的用户可见策略）——未确认前不实现对应持久行为、不补造默认值，见 `docs/plan.md` 阻断表。

### SPEC-SET-01 首版唯一设置为布尔记忆开关
- 规范：`contributes.configuration` 恰有一个属性 `abcdesk.rememberPracticeSettings`：类型 boolean、默认 true、可从 VS Code 用户 / 工作区设置调整；首版不增加其他设置（尤其路径 / 命令 / URL 类）。
- 验证：auto
- 里程碑：M0
- 依据：D0 设计 §5、§7；计划 §10（设置与恢复已确认）

### SPEC-SET-02 恢复范围与前提
- 规范：持久恢复以"记住每个文件的练习设置"开启为前提，适用于已保存文档；没有可用记录时使用默认值；未保存新文档仅保留会话内设置，首次保存后可靠关联才进入持久保存流程；恢复设置本身不准备音频、不起播，也不新建已经关闭的预览。
- 验证：manual
- 里程碑：M0
- 依据：设计 §5；计划 §7 清单第 12 项

### SPEC-SET-03 曲目级音乐设置恢复
- 规范：按可靠曲目身份恢复速度百分比、整段循环与自动和弦伴奏开关（不套用记谱声部编号，也不把旧 BPM 保存为新曲速度）；同曲身份已确认时，这三项不因声部结构变化重置；无可用记录时用默认值（速度 100%、循环关闭、遵循该曲目初始播放配置）。
- 验证：manual
- 里程碑：M0
- 依据：设计 §5；计划 §10（设置与恢复已确认）

### SPEC-SET-04 声部静音恢复与清除
- 规范：先可靠识别为同一曲目，再比较有序声部清单（标识、显示名称及顺序），未变才恢复静音覆盖；声部增删、改名、改标识、重排或无法确认时，清除该曲目的旧静音覆盖，回到乐谱 / 初始播放配置，并提示"声部已变化，请重新检查发声设置"；不按"第几个声部"或显示名猜测身份，也不部分继承仍能匹配的声部；不同曲目即使共用 `V:1` 等标识也不继承静音；只在有效新版本正式应用时比较声部结构，不提前修改仍在播放的快照；暂时空白或解析失败不自动用空声部清单覆盖旧记录，恢复有效内容后再判断。
- 验证：manual
- 里程碑：M0
- 依据：设计 §5

### SPEC-SET-05 文件级界面偏好与不恢复项
- 规范：谱面与键盘提示显隐、键盘展开 / 收起与音域模式按文件共用恢复（隐藏时明确显示"提示已隐藏"和"显示提示"入口；模式为乐曲或完整 88 键，实际音域按当前曲目重新计算）；当前选曲仅在同一次预览中保留、不持久恢复，新预览默认第一首（选曲行为见 DOC 域）；播放位置不持久保存，重开及手动切曲归零，临时隐藏保留同曲同版本位置；正在播放、等待起播、选中音符、打开的菜单与未提交输入不恢复、不持久保存。
- 验证：manual
- 里程碑：M0
- 依据：设计 §5；计划 §10（设置与恢复已确认）

### SPEC-SET-06 记忆开关行为边界
- 规范：关闭 `rememberPracticeSettings` 时不从历史记录恢复或继续持久保存，但不立即改动当前预览的练习设置、不打断播放；重新开启不把旧记录强行覆盖到当前界面。
- 验证：manual
- 里程碑：M0
- 依据：设计 §5；计划 §7 清单第 12 项

### SPEC-SET-07 重置本文件练习设置
- 规范：预览"更多"提供"重置本文件练习设置"，先暂停或取消待起播请求再允许操作：恢复该文件共用的界面默认值，并清除该文件所有曲目的音乐设置覆盖；入口说明作用于本文件全部曲目，不修改 ABC 或学习记录、不自动起播、不新增公开命令；重置设置不代替停止或切曲操作；无内容更新时保留当前选曲和暂停位置，暂停应用了新版本则按既定规则归零并核验曲目。
- 验证：manual
- 里程碑：M0
- 依据：设计 §5；计划 §10（设置与恢复已确认）

### SPEC-SET-08 记录存储边界与写入校验
- 规范：使用 VS Code 的工作区状态保存必要的文件 / 曲目 / 声部标识与轻量设置，不写 ABC、学习档案或额外项目配置文件；不为状态恢复持久保存 ABC 全文、合成音频或播放位置历史；只保存已提交设置，过期或已取消预览任务不得覆盖更新后的记录；无效记录安全回退，不恢复失效的源码范围或音符选择；迁移遇目标已有记录时来源记录不覆盖或混入目标，也不因冲突自动删除（迁移规则见 LIFE 域）。
- 验证：manual
- 里程碑：M0
- 依据：设计 §5；计划 §7 清单第 12 项
