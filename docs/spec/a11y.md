# A11Y：无障碍与焦点

> 依据：D0 设计 §4（键盘、焦点与无障碍）、§3；计划 §7 清单第 6、9 项与"M1 布局与本地化验收补充"。
> 本域与 CMD 域分工：命令数量、分组发现与共用规则见 CMD；本域定义按键语义细节、焦点原则与无障碍验证。
> 全部条目采用 manual 验证（登记见 `docs/manual-checks.md`）。
> 阻断：P06（焦点回退目标、ARIA 与播报描述细节）——未确认前不实现对应细节，见 `docs/plan.md` 阻断表。

### SPEC-A11Y-01 局部空格语义
- 规范：焦点在谱面或预览背景时切换播放 / 暂停；起播准备中再次按下取消起播并保留已提交位置，内部缓冲中按下暂停并取消续播，有待更新文档仍按暂停规则应用并归零；与播放 / 暂停按钮及命令共用状态规则，不可播放状态下不绕过禁用条件；长按只触发一次；按钮、开关、输入框、菜单等保留自身按键语义、不同时触发播放；不拦截输入法组合输入或带修饰键的组合键；源码、学习记录、其他视图及外部 agent 的空格不控制音乐。
- 验证：manual
- 里程碑：M0
- 依据：设计 §4；计划 §7 清单第 9 项

### SPEC-A11Y-02 点击谱面与焦点保留
- 规范：点击谱面音符定位对应源码、焦点留在预览（不因点击转移焦点）；显式"转到源码编辑"（见 CMD-12）才转移焦点；若源码未显示，在其他编辑器组显示，不把当前预览替换成后台标签；版本不一致时禁用旧位置映射。
- 验证：manual
- 里程碑：M0
- 依据：设计 §4

### SPEC-A11Y-03 焦点进入与恢复
- 规范：主动"打开音乐预览"进入预览时首次优先聚焦可用的播放按钮，未就绪时聚焦预览容器；从源码执行播放或从光标播放（含按需创建 / 显示预览）保留源码焦点；文件自动更新、音频加载完成、播放高亮均不抢焦点，加载完成后不把用户从当前输入处拉回播放按钮；隐藏提示或重建移除了当前聚焦元素时，在焦点仍属于预览的前提下恢复到合理的现存控件或容器；若用户已转到源码或其他区域，不抢回来。
- 验证：manual
- 里程碑：M0
- 依据：设计 §4；计划 §7 清单第 9 项

### SPEC-A11Y-04 Tab 顺序与控件按键
- 规范：Tab / Shift+Tab 按界面顺序导航、不创建循环焦点陷阱；谱面与键盘滚动区可用键盘访问，但不把每个音符或 88 个琴键加入 Tab 顺序，逐音查阅通过原生源码编辑器完成；方向键遵守当前控件语义（进度条调整进度、菜单选择选项、滚动区浏览），不全局解释为快进；按钮的 Enter / 空格按控件语义激活；窄宽 / 低高度布局切换时视觉与 Tab 顺序一致，尺寸变化不提交未确认输入或误触发播放；菜单可用键盘滚动、聚焦项不被驻留控制条遮住、关闭菜单后按既定规则返回触发控件。
- 验证：manual
- 里程碑：M0
- 依据：设计 §4；计划 §7（M1 布局与本地化验收补充）

### SPEC-A11Y-05 Esc 与焦点出口
- 规范：Esc 关闭当前菜单或取消未提交编辑，不暂停、不停止、不关闭预览；通过 Esc 或菜单内关闭操作退出时回到触发按钮，主动点击其他控件或显式导航则遵从用户指定的焦点目标；不接管 VS Code 的命令面板、编辑器组切换、关闭标签页等原有操作；保留 VS Code 原有的离开 webview 途径与显式转到源码操作。
- 验证：manual
- 里程碑：M0
- 依据：设计 §4

### SPEC-A11Y-06 可访问名称与状态播报
- 规范：交互控件提供可访问名称并随状态同步（例如起播准备期间播放按钮显示"取消起播"且同步更新可访问名称）；播放状态和错误适度播报、不逐音 / 逐帧通知屏幕阅读器；谱面 SVG 与琴键提供可访问描述、不呈现可演奏按钮的暗示；标题 / 曲名 / 路径可省略但须能取得完整文本，键盘与屏幕阅读器也能取得完整名称；无障碍标签纳入中英本地化覆盖（见 L10N 域）。（具体 ARIA 与播报描述细节待 P06。）
- 验证：manual
- 里程碑：M0
- 依据：设计 §4；计划 §7 清单第 9 项

### SPEC-A11Y-07 视觉可区分与高对比度
- 规范：查阅标记与播放高亮可区分、不只靠颜色区别（细节见 PLAY-11）；浅色 / 深色 / 高对比度主题下不破样（使用 `--vscode-*` 变量）；焦点可见性满足主题要求；关键状态不只靠颜色或省略号表达；谱面节点重建后查阅 / 播放标记与焦点正确重现，不复用失效的 DOM / 几何坐标。（焦点可见性与高对比度细节待 P06。）
- 验证：manual
- 里程碑：M0
- 依据：设计 §4、§3；计划 §7 清单第 6 项

### SPEC-A11Y-08 无鼠标全流程与平台限制记录
- 规范：无鼠标走通进入、控制、滚动与离开预览；验证实际跨编辑器组显示、命令面板上下文与编辑器组切换仍可用、播放按需打开、webview 按键传递和重建行为；记录平台限制清单（CSP、音频、按键、生命周期）；不能仅凭 DOM 设计认定无焦点陷阱。
- 验证：manual
- 里程碑：M0
- 依据：设计 §4；计划 §7 清单第 9 项

### SPEC-A11Y-09 谱面纸张外观与主题适配
- 规范：预览谱面按纸张外观呈现：白色谱纸、黑色谱面与文字，不随 VS Code 浅色 / 深色 / 高对比度主题变化；页面其余 UI 使用 `--vscode-*` 变量跟随主题；谱面元素不继承主题前景色、不因主题切换降低纸面与谱线的对比度；预览与导出的白底黑谱外观一致（导出见 EXP-06）。
- 验证：manual
- 里程碑：M0
- 依据：设计 §3（预览页线框）；计划 §7 清单第 6 项；M0 暗色主题实测（abcjs 默认 `currentColor` 谱线在白纸上对比度不足）
