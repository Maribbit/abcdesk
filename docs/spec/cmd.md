# CMD：命令与入口

> 示范域，已全量蒸馏 D0 设计 §2、计划 §5 第 20 条与 §7 清单第 1 / 9 / 13 项。
> 条目 ID 一经分配永不回收或重排（见 00-index.md）；被引用名以本文件为准。

### SPEC-CMD-01 公开命令恰为八个
- 规范：`contributes.commands` 恰有 8 个命令，ID 集合固定为 `abcdesk.openPreviewToSide`、`abcdesk.togglePlayback`、`abcdesk.stop`、`abcdesk.playFromCursor`、`abcdesk.playFromSelectedNote`、`abcdesk.goToSource`、`abcdesk.exportMidi`、`abcdesk.exportSvg`，均以 `abcdesk.` 为前缀；不增加窗口级停止、隐藏 / 显示提示或循环切换等公开命令。
- 验证：auto
- 里程碑：M0
- 依据：D0 设计 §2；计划 §10"工作名与基础命令已确认"

### SPEC-CMD-02 命令分组与发现方式
- 规范：命令面板名称以 `ABC Desk:` 为分组前缀（`contributes.commands` 的 category 为 `ABC Desk`）；两个起播命令的标题以括注标明位置来源（`从光标播放（源码）` / `从所选音符播放（预览）`，英文 `Play from Cursor (Source)` / `Play from Selected Note (Preview)`），不改命令 ID、不拆分命令分组；命令可在相关上下文的命令面板发现并由用户自行绑定；不新增工作台级默认组合键（不声明 `keybindings` 贡献点）。
- 验证：auto
- 里程碑：M0
- 依据：D0 设计 §2；计划 §10"按键与焦点已确认"

### SPEC-CMD-03 打开预览三个直接入口共用同一命令
- 规范：ABC 编辑器标题栏按钮、命令面板、资源管理器 `.abc` 右键菜单共用 `abcdesk.openPreviewToSide`；首次在侧边创建，同文件已有预览时显示并复用、不重复创建；资源管理器入口不要求先打开源码；命令面板无当前 ABC 目标时允许选择一个文件，取消不创建预览；只显示预览，不起播。
- 验证：auto
- 里程碑：M0
- 依据：D0 设计 §2

### SPEC-CMD-04 目标解析优先级
- 规范：明确目标（编辑器 / 资源管理器菜单传入的文件、预览按钮所属面板）优先，目标无效或已销毁时不回退到另一个文件；无显式目标时使用调用前的活动编辑器上下文（音乐预览绑定的文件或当前 ABC 文本文档），预览在前台时不误选仍保留的源码编辑器；命令面板临时获得焦点不改变调用前的音乐上下文；多个文件同名时按文档标识区分，不按显示名匹配。
- 验证：auto
- 里程碑：M0
- 依据：D0 设计 §2（目标解析与可用性规则）

### SPEC-CMD-05 无目标不执行、不回退
- 规范：学习记录、其他语言文件或无编辑器时视为无目标：普通控制命令不可用，直接调用时说明缺少目标且无副作用；不回退到最近使用 / 最近播放的预览，不弹预览选择器；仅 `abcdesk.openPreviewToSide` 允许文件选择。
- 验证：auto
- 里程碑：M0
- 依据：D0 设计 §2

### SPEC-CMD-06 未保存 ABC 新文档为有效目标
- 规范：语言模式为 ABC 的未保存新文档属于有效源码目标，沿用现有打开 / 播放命令；不增加新命令、不强制保存；预览标明"尚未保存"。
- 验证：auto
- 里程碑：M0
- 依据：D0 设计 §2、§6

### SPEC-CMD-07 播放类命令按需打开预览
- 规范：从 ABC 编辑器执行"播放 / 暂停"的播放分支或"从光标播放（源码）"，可在侧边创建或显示对应预览并保留源码焦点；渲染与音频准备完成后仅执行仍有效的请求；"从光标播放（源码）"无有效映射时提示，不改为从头播放；停止等非起播操作不为控制音乐新建预览；按需打开仅限用户明确的播放请求，打开文件、切换编辑器、外部修改等被动场景不触发；预览隐藏时明确起播须先显示对应预览，不提供隐藏面板后台发声。
- 验证：auto
- 里程碑：M0
- 依据：D0 设计 §2

### SPEC-CMD-08 两个起播命令的上下文分离
- 规范：`abcdesk.playFromCursor` 只取执行时刻的当前 ABC 源码光标；可靠确定曲目与音符时可显式跨曲起播，按需打开预览并保留源码焦点；无有效映射时提示，不切曲、不从头播放、不绕过待更新规则。`abcdesk.playFromSelectedNote` 取预览内的当前目标音符（谱面点选或源码光标命中维护的同一目标，见 SPEC-PLAY-11 / 12）与起播映射；无目标时提示，不回退读取执行时刻的光标，不播放渲染失败后的只读旧谱。
- 验证：auto
- 里程碑：M0
- 依据：D0 设计 §2

### SPEC-CMD-09 播放与暂停控制当前曲目
- 规范：`abcdesk.togglePlayback` 控制当前曲目，不跟随光标切曲，首次默认第一首；播放分支可按需显示预览并保留源码焦点；起播准备中再次执行取消起播并保留最后已提交位置，内部缓冲中执行则暂停并取消续播；有待更新文档时按暂停规则应用并归零；无有效选曲时提示选择。
- 验证：auto
- 里程碑：M0
- 依据：D0 设计 §2

### SPEC-CMD-10 停止与取消始终可达
- 规范：`abcdesk.stop` 在目标预览或起播请求存在时可用：停音、回到当前曲目开头、取消起播；不改选第一首、不要求最新内容可解析、不新建预览；停止与取消请求不因音频尚未就绪或内容错误而失效；不增加窗口级停止命令，无目标页面需要停音时先回到对应源码或预览。
- 验证：auto
- 里程碑：M0
- 依据：D0 设计 §2

### SPEC-CMD-11 命令与预览按钮共用操作规则
- 规范：命令与预览内按钮（含谱面 / 预览背景的局部空格）共用操作规则与取消语义；菜单可见性、命令启用条件和执行时校验分别处理；不能仅凭隐藏 / 禁用入口保证安全。
- 验证：auto
- 里程碑：M0
- 依据：D0 设计 §2、§4

### SPEC-CMD-12 转到源码编辑
- 规范：`abcdesk.goToSource` 目标为当前预览的来源文档并显式转移焦点（点击谱面音符不转移）；无有效音符映射时只打开来源文件，不套用旧偏移；来源标签已关闭但文件仍可读取时按绑定 URI 重新打开该文件并显式转移焦点，预览继续绑定该文件（磁盘内容有变化时按常规换版规则推送，未变化不推送以保留播放位置），不套用旧位置偏移；仅文件被删除 / 无法读取时说明原因，不自动新建同路径文件。
- 验证：auto
- 里程碑：M0
- 依据：D0 设计 §2、§3；docs/decisions.md"转到源码编辑在来源标签关闭后重新打开"

### SPEC-CMD-13 导出命令的目标与快照
- 规范：`abcdesk.exportMidi` 与 `abcdesk.exportSvg` 使用命令执行时目标文档（ABC 源码或预览所绑定文档）的当前内容快照，包含未保存修改；目标解析同 SPEC-CMD-04；多曲目每次确认一首；不代为保存 ABC、不使用落后的播放 / 预览版本；无预览时独立准备数据，不要求先播放或加载音色；无有效输出时说明原因，不回退旧数据。
- 验证：auto
- 里程碑：M0
- 依据：D0 设计 §2、§3

### SPEC-CMD-14 迁移来源状态页例外
- 规范：迁移冲突后的来源状态页不再是可控音乐目标：不执行旧绑定的播放、定位、设置修改或导出，也不把命令静默转交目标文件；只能通过明确的目标预览入口重新进入正常目标解析。
- 验证：auto
- 里程碑：M0
- 依据：D0 设计 §2、§6；计划 §5 第 20 条

### SPEC-CMD-15 编辑器标题栏预览入口以图标按钮呈现
- 规范：编辑器标题栏的预览入口使用命令贡献的 `icon` 以图标按钮呈现（首版使用内置 codicon，图标不本地化）；不以纯文字标题占据标题栏宽度；命令面板与资源管理器右键入口维持文字标题呈现；图标仅为呈现层细节，不改变命令 ID、可见性条件与复用行为。
- 验证：auto
- 里程碑：M0
- 依据：D0 设计 §2 菜单贡献点细节（图标待实现）

### SPEC-CMD-16 编辑器右键菜单起播入口

- 规范：`.abc` 编辑器的右键菜单提供"从光标播放"入口（`editor/context` 菜单贡献，可见条件 `resourceLangId == abc`），与命令面板共用 `abcdesk.playFromCursor`：只加菜单入口，不新增命令与默认组合键；执行语义与命令完全一致（保留源码焦点、按需创建 / 显示预览、无有效映射时提示、不从头播放，见 CMD-07 / 08）。
- 验证：auto
- 里程碑：M0
- 依据：docs/decisions.md"两个起播命令的可见入口"；D0 设计 §2 命令表

### SPEC-CMD-17 预览面板标题栏跳转源码入口

- 规范：预览面板标题栏提供"转到源码编辑"入口（`editor/title` 菜单贡献，可见条件 `activeWebviewPanelId == abcdesk.preview`），与命令面板共用 `abcdesk.goToSource`：以命令贡献的内置 codicon 图标按钮呈现（图标不本地化，同 CMD-15）；只加入口，不新增命令与默认组合键；多预览并存时各入口作用于所在面板的来源文档；目标、焦点与无映射行为不变（见 CMD-12、CMD-05、A11Y-02）。
- 验证：auto
- 里程碑：M0
- 依据：docs/decisions.md"预览面板返回源码的标题栏入口"；D0 设计 §2 命令表
