## 当前阶段：M0 前置

骨架就绪后的工作次序：

1. 澄清 G01（M0 / M1 验收边界）——阻断里程碑判定，不阻断规格补全。
2. 其余 spec 域按序补全蒸馏（每域：先补条目并注明依据，同步绑定测试或占位，再进入实现）：
   ENV → LIFE → STATE → DOC → SET → PLAY → PERF → EXP → L10N → A11Y
3. M0 spike 按 archive 计划 §7 清单执行；实测值与结论回填本文件（E02）与对应 spec 条目。

### M0 spike 范围（对齐 archive 计划 §7）

- 激活、命令目标解析与按需预览、渲染 / 播放 / 联动、外部 agent 写入更新、取消与性能保护、Remote / 受限模式、独立导出路径。
- `engines.vscode` 当前 `^1.75.0` 仅为开发基线；终值待 E03 实测后回填。

## 范围红线（浓缩）

- P1 后置：TreeView（会话 / 练习库）、LM tools、选区循环、练习库元数据约定。
- 明确不做（v0.1）：演奏输入捕获与自动评分、AI 对话集成、webview 内重建编辑器、云端 / 账号 / 遥测 / 网络请求、vscode.dev 浏览器入口、整集拼接与批量导出、超限绕过入口与用户性能调参、状态栏项、walkthrough / 首启通知、Markdown 内 abc 代码块、自定义谱面编辑器 UI。
- 职责边界：插件不集成 AI 对话；学习模板由用户与外部 agent 维护，不是工具运行前提。

## 工程约定速览

- 命令与设置：见 `docs/spec/cmd.md`、`docs/spec/set.md`（由绑定测试守住，勿在实现中私自增减）。
- 分层：`src/core` 不 import vscode；`src/extension` 只用 vscode API 与 `workspace.fs`；`src/webview` 只经消息桥（详见 `docs/conventions.md`）。
- 验证：`npm run check`（typecheck + lint + vitest + spec:check）全绿才算完成。
