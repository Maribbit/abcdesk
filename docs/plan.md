## M4 上架前置（评估，未执行）

以下为打包 / 发布前需要处理的事项；当前只登记，不执行 VSIX 打包或商店发布。

- 图标与资产：`package.json` 无 `icon`，仓库无 PNG 图标；需补方形 PNG（至少 128×128，Marketplace 不接受 SVG 作为扩展图标）。
- 打包范围：无 `.vscodeignore`，开发文件（`src/`、`test/`、`docs/`、`scripts/`、`samples/`、配置与 source map）会进入 VSIX；需显式忽略，并保留 `out/`、`media/`、`l10n/`、`package.nls*.json`。
- 依赖与构建：`abcjs` 虽由 esbuild 打包，仍列在 `dependencies`，会被 vsce 连带打入 `node_modules/abcjs`；应移到 `devDependencies` 或显式忽略 `node_modules`。`out/` 被 `.gitignore` 忽略且无 `vscode:prepublish`，需补构建钩子，避免打出缺失或过期产物。
- 发布元数据：`publisher` 仍为 `abcdesk`（需确认已在 Marketplace 注册或改为实际 ID）；缺 `repository` / `bugs` / `homepage` / `keywords`。`repository` 同时决定 README 相对链接与截图的解析。
- 商店材料：缺 `CHANGELOG.md`、`SUPPORT.md`、根级 `THIRD_PARTY_NOTICES` 与隐私说明；README 目前是开发状态说明，需改为用户向介绍并补截图。abcjs（MIT）声明未随 bundle 保留，FluidR3（CC BY 3.0）与 codicons（CC BY 4.0）声明目前只在 `media/` 内，需汇总随包分发。
- 兼容性：`engines.vscode` 的 `^1.75.0` 仍是开发基线，需 E03 实测后回填；Remote / 受限模式在商店版本的声明需复核。
- 发布通道：Azure DevOps 全局 PAT 将于 2026-12-01 退役，后续应使用 Marketplace Trusted Publishing（GitHub Actions / Azure Pipelines OIDC）；当前无 CI 发布配置。

非阻塞建议：`galleryBanner.color`、关键词、商店截图 / GIF、`PRIVACY.md`、`SECURITY.md`。
