# 人工验证登记（manual checks）

`docs/spec/` 中验证方式为 `manual` 的条目在此登记；`scripts/spec-check.mjs` 双向校验：
每个 manual 条目至少有一条登记，所有 `[SPEC-域-序号]` 引用必须能在 spec 中定义。

登记格式（引用置于列表项中）：

```text
- [ ] [SPEC-<域>-<序号>] 场景与步骤；判据（预期结果）。
```

## 登记

- [ ] [SPEC-ENV-02] 在不受信任工作区中执行打开、预览、播放、导出与设置读取；判据：与信任模式行为一致、不弹信任请求、不读取工作区路径 / 程序 / URL 类设置、写入只经原生保存对话框。
- [ ] [SPEC-ENV-03] 用含 HTML / 脚本片段的标题与声部名、含 `%%MIDI program` 与外部资源指令的 ABC 测试；判据：全部按文本渲染、无资源加载与脚本执行、CSP 无远程白名单。
- [ ] [SPEC-ENV-06] 在 WSL 或 SSH 远端完成打开、预览、播放、外部写入更新、导出保存；判据：全部可用，记录音色加载时长与限制清单。
- [ ] [SPEC-ENV-07] 以开发者工具网络面板观察预览、播放、导出全程（含 `%%MIDI program` 测试）；判据：零外部请求（abcjs 默认远程音色地址未被触发）、无遥测。
- [ ] [SPEC-ENV-09] 未打开 ABC 的工作区启动后在 Running Extensions 面板核对；判据：扩展未激活；打开 `.abc` 激活后不创建预览、不加载音色、不弹通知；记录激活耗时与打包体积。
- [ ] [SPEC-LIFE-01] 同时打开两个 .abc 文件并分别预览，切换活动编辑器、反复操作入口；判据：各自独立预览且同文档复用、不替换当前练习、绑定不随切换改变、无跟随 / 固定开关。
- [ ] [SPEC-LIFE-02] 新建未保存 ABC 文档执行预览、播放与联动，并检查保存 / 另存为 / 放弃流程；判据：可预览播放且不强制保存、"尚未保存"提示不反复弹出、取消操作不破坏预览、插件不代为保存或缓存全文。
- [ ] [SPEC-LIFE-03] 对已打开预览的文档执行首次保存、重命名与目录移动；判据：预览与设置接续、路径与标识更新、先暂停取消旧请求、内容未变保留位置、不可确认关系时不迁移。
- [ ] [SPEC-LIFE-04] 制造目标冲突（目标已有预览或设置记录）后执行可靠迁移；判据：目标优先、来源页转为只读迁移状态页（不可播放 / 定位 / 改设置 / 导出）、仅显式入口可进入目标、不自动关闭或抢焦点。
- [ ] [SPEC-LIFE-05] 对已保存且已预览的文件执行另存为；判据：原预览仍绑定原文件、设置不复制到新路径、新文件须主动打开才预览、仅关闭源码标签不影响预览。
- [ ] [SPEC-LIFE-06] 删除已预览文件（含无未保存缓冲区的场景）并观察状态页；判据：立即停音、旧谱仅供参考不可播放 / 导出、不自动重建或改绑；保留缓冲区时按文档继续并提示磁盘状态。
- [ ] [SPEC-LIFE-07] 恢复刚删除的源文件使路径重新可读；判据：预览重新校验并应用、位置归零、不自动播放、不复活已关闭预览。
- [ ] [SPEC-LIFE-08] 用外部工具对已预览文件做原子替换、快速删除重建与乱序写入；判据：不误判永久丢失、状态转换正确、确认不可用后及时停音。
- [ ] [SPEC-LIFE-09] 检查插件无 AI 对话界面与 chat 命令、不创建或解析 learning-guide.md / profile.md / session.md、连续操作播放器后 git status 无改动；判据：全部边界成立。
- [ ] [SPEC-STATE-01] 按 §3“主要状态与可用操作”逐状态核对（空白 / 准备中 / 就绪未准备 / 播放中更新 / 渲染失败 / 音频失败 / 告警 / 未保存 / 来源不可用）；判据：各维度独立表达、不混同（如音频失败不使谱面失效、资源就绪不等于发声）。
- [ ] [SPEC-STATE-02] 制造异步竞态：准备中取消 / 隐藏 / 关闭 / 被接替 / 停止后连续操作，观察晚到结果；判据：晚到结果不复活声音 / 诊断 / 状态，停止后旧定位不移动位置，新请求不被旧取消清掉。
- [ ] [SPEC-STATE-03] 用可触发渲染失败的 ABC 内容测试，再修复恢复；判据：旧谱带明确参考标记且禁播禁定位、无旧谱时错误占位、恢复后自动更新不起播、播放中不因新内容错误提前切版。
- [ ] [SPEC-STATE-04] 构造音频准备失败与超时，观察降级与重试；判据：谱面与可靠源码定位保留、仅音频能力受限、"重试并播放"需用户发起且不无限自动重试。
- [ ] [SPEC-STATE-05] 打开空白文件与合法全休止符文件；判据：空白→"文件尚无音乐内容"+入口、不报红不填示例；全休止符→不视为空文件、键盘说明无音高提示。
- [ ] [SPEC-STATE-06] 制造解析告警与资源 / 音色错误；判据：可靠诊断进 Problems、不可靠留详情且不编行号、音色错误不标成 ABC 行错误、修复后诊断清除、不自动打开 Problems。
- [ ] [SPEC-STATE-07] 播放中修改文件，分别在暂停 / 停止 / 自然结束 / 隐藏 / 被接替时观察应用；判据："暂停后应用"标记暂停前可见、应用时核验归零且不自动起播、循环回边界不算自然结束。
- [ ] [SPEC-STATE-08] 检查状态区展示与入口；判据：关键状态就地可见、后果提示在动作前可见、隐藏提示不隐藏状态、旧谱禁用时"转到源码编辑"仍可用且不套旧映射。
